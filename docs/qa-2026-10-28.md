## 01:48–01:51 EDT | Interpolated alighting-time safety fix; CI and Pages verified

**Scope:** Bus Buddy only. No job searches/alerts for Trey, paid APIs, purchases, or paid tiers.

### Evidence and incremental fix
- Inspected GitHub `main` after [d706120](https://github.com/clarenceandbridgettallen-ops/trey-bus-buddy/commit/d706120303782bbcbab23cabc7db5f897c93fa96), current `index.html`, regression harness, sync script, stored GTFS-derived files, tracker audit, and official Coast RTA pages. No previously successful routing, fare, speech, or mobile features were intentionally removed.
- **Reproducible source defect:** `renderTrip()` disabled START MY TRIP when the **first departure** was interpolated, but permitted spoken guidance when a **later alighting time** was interpolated. `preferTrip()` could also select an earlier uncertain-arrival option over a later fully published-time alternative. Since 4,376 of 5,165 stored stop-time records have blank arrival/departure fields, this matters.
- **Fix:** For a proposed trip with *any* interpolated boarding or alighting time, keep the itinerary as an explicitly uncertain preview, display a Coast RTA confirmation warning, and disable START MY TRIP. Prefer a fully published-time, guide-eligible alternative over an earlier uncertain-time option. This does not make a straight-line walking path safe or certify a bus's actual arrival.
